Welcome to NeoCMS 3

A database-free CMS with drafts, revisions, scheduled publishing, and rather fewer excuses for editing live HTML.

Edit and publish

Open Pages, choose a page, and select any region carrying the configured editable class.

The editor offers Save Draft (private), Schedule Publish, and Publish Now, which creates a revision before replacing the public page.

Pages and revisions

Administrators can create, duplicate, rename, and delete pages. The New page section under the list in Pages is a three-step wizard: choose a template, name the page (the filename is generated for you), then choose a navigation group. The new page stays a private draft until it is published; publishing creates the file and adds it to the chosen menu.

Use Create Template on any page in the list to offer it as a template, and Delete in the template list to stop offering one. Editors can restore earlier revisions from Tools.

Deleted pages retain a restorable snapshot: editors can bring one back with Recover in the Dashboard's Deleted pages list, because accidents should be reversible rather than memorable.

Media and SEO

The media library uploads images, documents, video and audio, sorts them by type, records alternative text or link text, and reports usage counts. In the editor, the Media library button inserts an uploaded file at the cursor. Executables and files containing code are refused.

The SEO dialogue manages titles, descriptions, canonical URLs, Open Graph images, and indexing instructions.

Shared content and menus

Regions marked with data-neo-shared can be updated across every page. Open Navigation Menus to edit, rename, or delete menus; changes propagate to every page. Menus are created by your web developer, not the CMS: Site Scan and the menu dialogue's scan button find navigation in the site files (primary and secondary are detected automatically).

Schedule and preview

Editors may queue a future release. The desktop, tablet, and mobile icon buttons resize the preview without altering page markup.

Users, checks and activity

The accessibility checker catches common authoring problems before publication. The dashboard lists drafts, schedules, deleted pages you can recover, recent activity, writable-directory warnings, and recommendations.

Everyone can update their display name, email address and password from Tools > Users. An Editor edits and publishes content; an Administrator can also manage pages, menus and shared content, and add, invite, edit, block or delete users. Accounts in config.local.php stay managed there. Important: CMS-created accounts are stored in the data folder, so on a live site set dataDirectory in config.local.php to an absolute path outside the web root; administrators see a Dashboard recommendation until it is.
